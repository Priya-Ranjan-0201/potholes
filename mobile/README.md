# ScamRoad — Mobile App

Expo (React Native) app for Android.

> **Status:** Stub only. Will be initialised with `npx create-expo-app` in **Phase 11**.

## Planned Features

- Citizen reporting of road defects via camera
- Offline photo capture with GPS tagging
- Push notifications for nearby hazards
- Multilingual support (Hindi, English, regional languages)

## Initialisation (Phase 11)

```bash
cd mobile
npx create-expo-app@latest . --template blank-typescript
```
